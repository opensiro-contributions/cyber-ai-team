## 2. Selected construction hypothesis and operator outcome

**Target transition:** S3*=— -> S3*=C

**Function-specific disturbance:** HYPOTHETICAL: an executive action carries coherent-looking but false company-state evidence or a stale strategy assumption which passes deterministic thresholds before a downstream internal action.

**Proposed C capability (P0):** A developer configures an independent read-only Observer role that examines a frozen executive snapshot and independently accessible primary evidence, chooses accept, object with attributable findings, or escalate as unknown. A typed review is action/run bound; a genuine objection returns via the existing observer_blocks hold and later revised evidence may be re-reviewed. No reviewer gets tool, financial or policy rights.

**Best native operator alternative:** Keep [backend/src/cyber_team/operations/executive.py](https://github.com/Hyper-AI-Lab/cyber-ai-team/blob/525401e40f34863cc7f4d3b053d437ce7709912f/backend/src/cyber_team/operations/executive.py) deterministic _run_observer_review and owner-side approval; this is simpler and already blocks certain high-severity cases, but a named Observer manifest alone does not supply discretionary external-evidence critique.

**Expected user benefit:** HYPOTHETICAL earlier detection of semantic inconsistency before a safe internal executive action; correctness, false positives and cost NOT_MEASURED. An operator can still prefer current deterministic checks.

**Architectural sufficiency argument:** Reuse [backend/src/cyber_team/agents/manager.py](https://github.com/Hyper-AI-Lab/cyber-ai-team/blob/525401e40f34863cc7f4d3b053d437ce7709912f/backend/src/cyber_team/agents/manager.py) AgentManager.invoke_agent with an Observer-only read scope and [backend/src/cyber_team/operations/executive.py](https://github.com/Hyper-AI-Lab/cyber-ai-team/blob/525401e40f34863cc7f4d3b053d437ce7709912f/backend/src/cyber_team/operations/executive.py) review/hold pipeline. The missing first-party link is validated evidence-aware discretionary judgment tied to the actual still-pending action and a durable returned objection. Independent decision must survive the counterfactual in which fixed rule checks run unchanged.

## 5. Proposed acceptance and stop gates

**Future positive test:** Native executive test injects contradictory primary evidence and observes an independent reviewer objection, an exact action blocked before any side effect, a durable review and later successful authorized recheck when evidence is corrected.

**Future negative test:** Missing, stale, forged, invalid or failed reviewer in explicit enforce mode cannot silently allow action. An unconfigured default mode retains existing deterministic behavior, unrelated safe actions and parent restrictions.

**Proposed falsifier:** Existing native equivalent autonomous evidence review; no independently available evidence; non-binding objection; stale review incorrectly reused; parent gate bypassed or default behavior regressed.

**Validation state:** NOT_RUN for native tests; structural metadata validators do not prove the proposed capability.
